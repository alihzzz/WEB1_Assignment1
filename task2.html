Task 2 Overview

This webpage demonstrates a classic multi-column webpage layout created strictly without modern layout tools like CSS Flexbox or CSS Grid. Instead, it utilizes traditional CSS properties such as float: left, float: right, and block-level div elements.

Layout Implementation

The structural architecture consists of a full-width header at the top, followed by a navigation bar. The middle section is divided into two distinct floating columns: a fixed-width sidebar menu on the left and a flexible main content box on the right.

CSS Float & Clear Mechanics

When elements are floated, they are removed from the normal document flow. To prevent the footer from collapsing or overlapping into the middle content section, a clearing mechanism (clear: both) is applied to the footer element.
