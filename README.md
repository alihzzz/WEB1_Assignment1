## 📌 Project Overview
This repository contains the completed **Assignment 1**.

### Completed Tasks:
1. **Task 1: Personal Webpage & Profile Card** — Basic HTML semantics, headings, lists, image with border-radius, hover links, and CSS selectors (`element`, `.class`, `#id`).
2. **Task 2: Webpage Layout (Divs & Floats)** — Classic multi-column architecture using `float: left` and `float: right` with clearfix mechanics (no Flexbox or Grid).
3. **Task 3: Tribute Page (Cristiano Ronaldo)** — Dedicated page with dual Google Fonts (`Montserrat` & `Roboto`), timeline, lists, styled Wikipedia button, and custom image shadows.
4. **Task 4: Tables & Forms Styling** — Academic performance table with `colspan`/`rowspan`, row highlighting (`.highlight-row`), `:nth-child` striping, and a fully styled course feedback form.
